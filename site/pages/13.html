Eight connections, one file

Hosts cap each socket. Ranges are split as the transfer runs and every byte lands at its final offset.

↺

Exact resume

Finished ranges are recorded as they land. Restart the app, the PC or the network and continue from the same byte.

▶

Streams to MP4

HLS playlists are fetched segment by segment and written out as one MP4 with ffmpeg.

⇄

Browser hand-off

The extension for Chrome, Edge, Brave and Vivaldi passes link and cookies to DM. Logged-in files just work.

⌂

A real Windows app

Tray icon, save-as dialog, progress window and finish actions like open folder or shut down.

Web UI and CLI too

The same list on localhost, and a command line for scripts: add, list, pause, resume.

Ready in one file.
