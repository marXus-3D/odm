DM

Striped is the slow socket. Hosts cap each connection, not each person, and TCP shares a busy link per flow. Then, instead of cutting the file into eight fixed pieces, DM lets every idle connection halve the largest remaining range and take the tail. The slow one ends up owning a sliver. Every range writes straight into one preallocated file at its own offset: no part files, no merge.

Parts list

Everything in the box, and nothing you have to assemble.

  • Native Windows windowDark by default, tray icon, save-as when a download arrives, progress while it runs, a dialog when it is done.
  • Background serviceRuns at sign-in if you want. Holds the list and keeps transferring with no window open.
  • Browser extensionSigned and shipped inside the installer. Catches downloads and streams, passes them over with cookies.
  • Exact resumeFinished ranges are recorded as they land. Restart the app, the PC or the router and it carries on from the same byte.
  • Finish actionsOpen the file or folder, or sleep, shut down or restart the PC when the last download lands.
  • Web UI and command lineThe same list on localhost, and a small command for scripts: add, list, pause, resume.

Install

One file installs the app, registers the browser hook and offers the extension. The same file uninstalls, and keeps your download list unless you choose to remove it.

Download DM-Setup.exe 
DM-Setup.exe -silent                 install with defaults
DM-Setup.exe -silent -no-startup     skip the sign-in entry
DM-Setup.exe -uninstall -silent      remove, keep the list
