Eight sockets, one file, no merge step

DM pulls a file over several connections at once, splitting the remaining bytes as it goes, and writes each piece directly to its final offset. The browser extension hands over the link with your cookies attached.

Why more connections are faster

Three effects, in the order they matter.

  1. Hosts cap each socket, not each user. Eight sockets get eight times the cap.
  2. TCP shares a bottleneck per flow. Eight flows claim eight shares, and each ramps its window on its own, which counts most on long high-bandwidth paths.
  3. Splits happen late, not up front. An idle connection halves the largest remaining range and takes the tail, so a slow connection ends up owning less of the file.

What the extension does

It watches for downloads in the browser and hands each one to DM through the browser's own native-messaging channel, together with the cookies for that site. Files behind a login download without any copying of headers or tokens by hand. Streaming video pages get a small button that sends the playlist across.

What is in the box

Native app

Dark Windows window with a tray icon, save-as and progress dialogs, a finished dialog, and finish actions: open, sleep, shut down, restart.

Background service

Runs at sign-in if you want. Holds the download list and keeps transferring while no window is open.

Web UI and command line

A local page for the same list, and a small command for scripts: add a link, list, pause, resume.

Browser extension

Ships inside the installer, signed. The installer offers it to your browser and shows the one click left to do.

Install

Run DM-Setup.exe. It installs to your user folder, so there is no administrator prompt. The same file removes DM again; your download list is kept unless you choose to remove it.

Download DM-Setup.exe, 28 MB

Unattended

For scripts and fresh machines:

DM-Setup.exe -silent installs with the defaults.
DM-Setup.exe -silent -no-startup skips the sign-in entry.
DM-Setup.exe -uninstall -silent removes it.
